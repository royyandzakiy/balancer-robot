# balancer-robot

Two-wheel self-balancing robot: Zephyr C++23 firmware (ESP32) and a Qt/QML desktop companion, talking over BLE.
Plan and decisions: [docs/plan.md](docs/plan.md).

Generated by [dalang](https://github.com/royyandzakiy/dalang) from the `zephyr` template
(https://github.com/royyandzakiy/zephyr-project-template); `companion-app/` from the Qt/QML C++ template.

## Layout

| Folder | What | Built with |
|---|---|---|
| `firmware/` | Zephyr app (`samples/` holds the template samples for now) | `west`, in the Zephyr devcontainer |
| `companion-app/` | Qt 6 / QML desktop app | CMake presets + vcpkg, on the host |
| `protocol/` | BLE wire format shared by both (planned) | — |
| `docs/` | plan, ADRs, RFCs | — |

The two halves never share a build. Shared at the root: `.clang-format`, `.clang-tidy`, `.clangd` (editor
behaviour), `.editorconfig`, `.cmake-format.yaml`, `.pre-commit-config.yaml`, `.github/`.

## Working on it: two windows

| Window | Open | Runs in |
|---|---|---|
| Firmware | repo root in VS Code → **Reopen in Container** → *Firmware (Zephyr)*; the window opens on `firmware/` | Zephyr devcontainer (`.devcontainer/firmware/`, macOS: `firmware-macos/`) |
| Companion | repo root in VS Code on the host (CMake Tools uses `companion-app/`), or `companion-app/` in Qt Creator | Windows host; Linux/WSL2 via `companion-app/scripts/setup-ubuntu.sh` |

Firmware commands: [NOTES.md](NOTES.md). Companion setup: [companion-app/EDITOR_SETUP.md](companion-app/EDITOR_SETUP.md).

## CI

| Workflow | Runs on changes to |
|---|---|
| `companion.yml` | `companion-app/**`, `protocol/**` — Windows clang-cl + Linux clang, GTest/QtTest/Qt Quick Test, Spix E2E |
| `samples.yml` | `firmware/samples/**` — board builds, twister on native_sim, Renode |
